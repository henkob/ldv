# LDV

Första publika testversionen av webbappen för La Dolce Vita, Sankt Anton 2027.

- Mobilanpassad startsida och fem huvudvyer
- Endast demonstrationsinnehåll, inga personuppgifter
- Program och deltagare för 2027 är inte importerade
- Original-SVG-logotypen ska föras in i nästa steg

Denna version är en förenklad testversion. Den tidigare ZIP-prototypen är inte fullständigt överförd.
